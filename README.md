# 💊 MediFind - Medicine Availability & Nearby Pharmacy Finder

A full-stack web application that helps people find medicines and nearby pharmacies with live stock availability.

## 🚀 Features
- 🔍 Medicine Search
- 🏪 Nearby Pharmacy Finder
- 📦 Live Stock Updates
- 🚨 Emergency Medicine Request
- 📍 Location-based Results

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Real-time:** Socket.io

## ⚙️ Installation

### 1. Clone the repo
```bash
git clone https://github.com/praveenkumarbera/medicine-finder.git
cd medicine-finder
```

### 2. Install dependencies
```bash
cd backend
npm install
```

### 3. Start MongoDB
```bash
brew services start mongodb-community
```

### 4. Run the server
```bash
node server.js
```

### 5. Open the app
Go to http://localhost:3000

## 📸 Project Impact
Helps patients find medicines without visiting multiple pharmacies — strong social impact in healthcare accessibility.
